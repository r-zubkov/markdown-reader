# Change registry

This registry is the persistent index for work requested after the accepted MVP. Lifecycle rules and state meanings are defined in [change-workflow.md](change-workflow.md).

Historical P00-P05 work is not backfilled. New IDs are immutable, monotonically increasing and never reused, including for rejected or superseded changes.
